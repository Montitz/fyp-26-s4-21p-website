Sprint plan

Each sprint lasts two weeks. This plan may change as we learn more, and we will note changes here.

  1. Sprint 1, 17 to 30 Oct Finalise the proposal and requirements, seed the starter catalogue, build the backend skeleton, and set up this website.
  2. Sprint 2, 31 Oct to 13 Nov Embed the catalogue, test the model on the hosting server, build the first age filter, and finalise the requirements document.
  3. Sprint 3, 14 to 27 Nov Run similarity search end to end in the app, add parent restriction rules, and log requests.
  4. Sprint 4, 28 Nov to 11 Dec Build parent reports and the admin catalogue portal, harden the prototype, and draft the user manual.
  5. Sprint 5, 12 to 25 Dec Demo the core pipeline at the mid-point, and start the labelled test set.
  6. Sprint 6, 26 Dec to 8 Jan Finish the labelled set, train the ranker, and build admin retraining, deployment and user management.
  7. Sprint 7, 9 to 22 Jan Evaluate against the baseline and run the safety check.
  8. Sprint 8, 23 Jan to 5 Feb Add optional features, run non-functional tests, and fix bugs.
  9. Sprint 9, 6 to 19 Feb Finish the documentation and marketing video, and give the final demo.
