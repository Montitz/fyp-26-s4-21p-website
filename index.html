Books and videos your child can explore safely

Children Book & Video Chatbot is a mobile app that recommends age-appropriate books and educational videos through a simple chat. Safety rules run first, and every suggestion explains why it was picked.

See what the app will do Read the project log

Why we’re building it

Children can find almost anything online, and open-ended search or AI tools can return content that is unverified or unsuitable for their age. We are building a catalogue-based alternative: a reviewed set of books and videos, hard age and safety filters applied before any ranking, and parent controls for each child.

Who uses it

Children

Type a topic or tap a suggestion, get a few picks with reasons, save favourites, and choose how results are shown.

Parents

Create a profile for each child, block topics, set how deep a topic can go at each age, and read reports comparing what was searched with what was recommended.

Administrators

Maintain the catalogue and user accounts, and retrain and deploy the ranking model, from a web portal.

Project objectives

  • Filter first. Apply age, maturity and parent-set rules before any scoring happens.
  • Match by meaning. Use a pretrained Sentence Transformers model to compare the child’s request with every catalogue item.
  • Learn from feedback. Train a small neural ranker offline, with an admin portal to retrain, evaluate and deploy new versions.
  • Measure the results. Compare against a TF-IDF baseline using Precision@5 and NDCG@5, and check that no returned item breaks a safety rule.
